# @horizon/types

> Shared TypeScript domain interfaces, entities, Enums, and API DTOs across the Horizon ecosystem.

## Contents
- **Task Types:** Task definitions, statuses (`DISCOVERED`, `COMMITTED`, `SUBMITTED`, `VERIFIED`, `REJECTED`), geospatial bounding boxes.
- **Submission Types:** Observation telemetry, media references, EXIF data, client timestamp signatures.
- **Verification Types:** AI verification signals, reviewer verdicts, consensus thresholds.
- **Token & Ledger Types:** Token balance DTOs, ledger transaction events, reward calculations.
