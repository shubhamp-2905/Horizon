# Verification Strategy

## Multi-Layer Verification Pipeline

```
Submission
   │
   ▼
[Stage 1: Deterministic Filtering]
   ├── EXIF Metadata & Geofence Check
   ├── Cryptographic Hash Duplicate Detection
   └── Time-Window Constraints
   │
   ▼
[Stage 2: AI Verification Signal]
   ├── Object Detection Score
   ├── Anti-Spoofing Authenticity Index
   └── Solar / Environment Sanity
   │
   ▼
[Stage 3: Peer Consensus Review]
   ├── Distributed Reviewer Allocation
   └── Stake-Weighted Majority Voting
   │
   ▼
[Stage 4: Authoritative Resolution]
   ├── Approve & Disburse Token Reward
   ├── Reject & Slash Stake (Fraud)
   └── Route Clean Dataset to Loupe Pipeline
```
