# Token Economy & Incentives

## Token Utility
- **Staking / Commitment:** Contributors stake micro-allowances from starter tokens to commit to tasks, mitigating spam reservations.
- **Contribution Bounties:** Dynamic token rewards scaled by task difficulty, urgency, and data fidelity.
- **Reviewer Bounties:** Reviewers earn shares of task verification bounties when participating in majority consensus.
- **Slashing & Penalties:** Sybil attempts, spoofed GPS telemetry, or stock photo submissions result in stake slashing and reputation degradation.

## Ledger Specifications
- Cryptographically verifiable append-only ledger entries.
- Double-entry bookkeeping model for all mints, stakes, payouts, and burns.
