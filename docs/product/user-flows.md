# User Flows

## Contributor Flow
1. **Onboarding:** Install app, create account, receive starter token stake.
2. **Task Discovery:** Cache offline map region, search available tasks in bounding box.
3. **Commit:** Reserve task with time-to-live (TTL).
4. **Data Capture:** Arrive at coordinates, capture photos with timestamp and sensor telemetry.
5. **Submission:** Upload queue syncs when connectivity is established.
6. **Reward Claim:** Receive notification upon verification consensus and balance update.

## Reviewer Flow
1. **Queue Access:** Access reviewer portal via Web Dashboard.
2. **Side-by-Side Review:** Inspect ground photos vs. satellite imagery, view AI confidence scores.
3. **Consensus Vote:** Approve, Reject, or Flag for Escalation.
4. **Validator Reward:** Earn reviewer bounty on consensus alignment.
